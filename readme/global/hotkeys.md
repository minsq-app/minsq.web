Navegação Direta entre Módulos (Teclas Numéricas)
Pressionar os números pula de uma página para a outra instantaneamente:

1: Dashboard
2: Hoje
3: Metas
4: Finanças
5: Saúde
6: Estudos
7: Foco
8: Notas
9: Perfil 
0: Configurações

Atalhos de Ação Rápida (Letras)
Esses atalhos não apenas mudam a página, mas já abrem o modal exato de criação no ponto de você começar a digitar:

CTRL + A (Saude): registra instantaneo 500ml de agua tomado
X (Help): ativa o modo ajuda da pagina
P (Saude): abre a aba saude e abre o modal de registrar peso 
N (Notas): Abre a aba de Notas já levantando o modal para Criar Nova Nota.
F (Finanças): Abre Finanças já levantando o modal de Novo Lançamento (Transação).
H (Hoje): Abre a página Hoje e levanta o modal de Nova Tarefa marcada para Hoje.
J (Tomorrow/Amanhã): Abre a página Hoje e levanta o modal de Nova Tarefa já marcada para Amanhã. (J fica estrategicamente do lado do H, lembrando o layout do Vim).

Terminal / Command Palette
K: Levanta o poderoso Terminal de Comandos do Minsq (o K-Modal) sobre qualquer página que você estiver.
Dentro do K-Modal: Você navega usando as setas ↑ ↓ ou as teclas W (sobe) e S (desce), apertando Enter para executar o comando.


Utilitários
Esc (Escape): Fecha de imediato qualquer Modal, Painel de Notificações, Modal do Terminal K, Menu ou Janela Sobreposta aberta na tela atual.
